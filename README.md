# Карточка товара — Teaboom

Тестовое задание: карточка товара «Ананасовый улун» (HTML / CSS / vanilla JS).

## Опубликованная версия
https://zibzib0116.github.io/testTeaboom/

## Запуск

Просто откройте `index.html` в браузере. Никакой сборки и зависимостей не требуется.

Либо через локальный сервер:

```bash
npx serve .
```

## Структура

- `index.html` — разметка карточки товара
- `style.css` — стили (адаптив: 1440 / 768 / 375)
- `index.js` — переключение фасовок, цена, старая цена, артикул
